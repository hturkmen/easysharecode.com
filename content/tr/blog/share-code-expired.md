## Don't Panic — It's Easy to Fix

If your share code has expired, there's no penalty, no fine, and no impact on your immigration status. An expired code simply means the temporary access key has timed out. Your underlying immigration permission is completely unaffected.

All you need to do is generate a new one. It takes about 5 minutes.

## Why Do Share Codes Expire?

Share codes are designed to be temporary for security reasons. The Home Office doesn't want a code floating around indefinitely that could potentially be misused. By setting expiry dates, they ensure that:

- Only current, valid codes can be used for verification
- You maintain control over who can check your status
- The system stays secure even if a code is intercepted

### Expiry Periods

| Code Type | Validity |
|-----------|----------|
| Right to work | 30 days |
| Right to rent | 90 days |

## How to Generate a New Share Code

The process is identical to generating your first code:

1. **Visit gov.uk** — go to [prove right to work](https://www.gov.uk/prove-right-to-work) or [prove right to rent](https://www.gov.uk/prove-right-to-rent)
2. **Verify your identity** — use your passport, BRP details, or identity document
3. **Select the purpose** — choose work or rent
4. **Get your new code** — displayed on screen and emailed to you

There's no limit to how many codes you can generate. Each new code is independent — generating a new one doesn't invalidate any existing valid codes.

## What If You Need a Code Right Now?

The most stressful scenario is discovering your code has expired at the worst possible moment — when an employer or landlord is waiting for it.

### If You Have Internet Access

Generate a new code immediately through gov.uk. The process takes about 5 minutes if you have your identity document handy.

### If You Don't Have Internet Access

This is where preparation pays off. If you'd stored your code in Apple Wallet using the [Easy Share Code app](https://apps.apple.com/gb/app/easy-share-code-uk/id6744980944), you'd have it available offline. But if your stored code has also expired, you'll need internet access to generate a fresh one.

## How to Prevent Expired Code Problems

### 1. Track Your Expiry Dates

Know when each of your codes expires. If you have codes for different purposes (work and rent), they'll have different expiry dates.

### 2. Set Up Reminders

Use the [Easy Share Code app](/share-code-wallet/) to get automatic notifications 7 days and 1 day before expiry. This gives you plenty of time to generate a fresh code.

### 3. Generate Fresh Codes Strategically

If you know you'll need a code for a specific event (job interview, flat viewing), generate a fresh one a day or two before rather than relying on an older code.

### 4. Store Codes in Apple Wallet

Even if a code expires, having it stored means you know exactly when it was generated and can quickly determine if you need a new one. The app clearly shows expiry status.

## Frequently Asked Questions

### Does an expired code affect my visa?

No. Your share code and your visa/immigration status are completely separate. An expired code has zero impact on your right to work, rent, or stay in the UK.

### Can I use an expired code?

No. When someone tries to verify an expired code on the Home Office system, it will show as invalid. They'll need a current, valid code.

### How quickly can I get a new code?

About 5 minutes, assuming you have internet access and your identity document. The code is generated instantly once you verify your identity.

### Can I generate a code in advance "just in case"?

Yes, but remember it starts expiring from the moment you generate it. A right to work code generated today will expire in 30 days regardless of whether you use it.

### My employer says my code doesn't work — is it expired?

Possibly. Check when you generated it. If it's been more than 30 days (for work) or 90 days (for rent), it's expired. Generate a new one and send it to them.

An expired share code is a minor inconvenience, not a crisis. Generate a new one, store it properly, and set up reminders so it doesn't catch you off guard again.
