# Easy Share Code UK - Website

Official website for the [Easy Share Code UK](https://apps.apple.com/gb/app/easy-share-code-uk/id6744980944) iOS app.

**Live:** [www.EasyShareCode.com](https://www.easysharecode.com)

## About

Easy Share Code UK helps people living in or visiting the UK to securely store, manage, and share their Home Office share codes.

## Tech Stack

- **Static Site Generator:** Hugo
- **CSS Framework:** Tailwind CSS (CDN)
- **Hosting:** GitHub Pages
- **CI/CD:** GitHub Actions
- **Languages:** 9 (EN, TR, DE, FR, ES, PT, PL, RO, IT)

## Local Development

```bash
# Install Hugo (https://gohugo.io/installation/)
# Then run:
hugo server
```

## Deployment

Automatic deployment via GitHub Actions on push to `main` branch.
